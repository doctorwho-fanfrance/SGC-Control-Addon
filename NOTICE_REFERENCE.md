# Reference / copyright boundary

The uploaded **Stargate Dial Simulator 2024 V1.0a** was inspected only as a functional and visual reference.
Its manual identifies the simulator as CC BY-NC-ND 4.0 and also notes Stargate franchise copyrights.

This addon therefore does **not** bundle, convert, extract, trace, or redistribute the simulator's SWF files, MP3 files, fonts, graphics, or executable resources.
The SGC-inspired GUI in this project is independently drawn with Minecraft/Forge primitives and original code.

Before any public release, use only artwork/audio you created yourself or have permission to distribute, and review the branding/IP implications of distributing a Stargate fan addon.
